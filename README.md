# Inventory Manager

Full-stack inventory and sales app built with Next.js, TypeScript and Supabase.

**Live demo:** https://inventory-app-cyan-kappa.vercel.app

## Features
- Add, edit and delete products (SKU, MRP, price, GST rate)
- Track stock levels
- Sell action that reduces stock and blocks sales at zero
- Recent sales log with timestamps

## Stack
Next.js (App Router), TypeScript, Tailwind CSS, Supabase (PostgreSQL), Vercel
